Dream-RSI — Recursive Self-Improvement via Replay Simulation

↗
Self-Directed Research

End-to-end implementation of the Dream-RSI framework (arXiv:2609.14858) — a recursive self-improvement system for automated code discovery. Built the full Discover-Evaluate-Store-Dream-Compare loop: Top-K candidate generation, correctness and runtime benchmarking, discovery trees with parent/child relationships stored in SQLite, three exploration policies (Greedy, Diverse, Adaptive), and offline dreaming that replays historical discovery trees under alternative policies without re-executing expensive computations. Recursive cycles switch the active policy based on replay reward signals. Parent-to-child delta tracking identifies genuinely productive search directions. Next milestone: formal three-term replay objective (quality minus cost penalty plus parallelism bonus) and replacing the deterministic coding agent with an LLM for autonomous implementation generation.

AgentForge — Multi-Agent Coding Harness with Meta-Debugger

↗
Self-Directed Research

Agentic coding harness that diagnoses and improves the workflow when an agent fails, rather than blindly retrying code generation. Planner analyzes the task and creates a structured spec. Repository Analyst inspects the codebase. Three parallel Coder strategies run simultaneously (minimal, robust, test_first) in isolated workspaces. Judge verifies each trajectory. SQLite-backed run IDs, trajectory traces, events, and results. FastAPI backend, Streamlit dashboard.

TrustLens — AI Detection Generalization Research

↗
Self-Directed Research

Controlled study on AI text detection generalization showing that random train/test accuracy is insufficient for evaluating AI detection reliability. Generated a 2,400-response dataset across 7 scenarios with balanced human/AI sources and multiple style templates. TF-IDF + Logistic Regression classifier. Standard random split: 93.8% accuracy. GroundedMind — Empirical Embodied Cognition Research

↗
Self-Directed Research

Empirical test of embodied cognition theory: does grounding language models in synthetic sensory experience improve concept representation, especially for novel/pseudoword concepts with no prior linguistic associations? Built a text-only baseline using SentenceTransformer embeddings with cosine similarity and softmax association distributions, a synthetic sensory world generator creating controlled multisensory experiences across eight attributes (color, texture, temperature, sound, movement, size, shape, emotion), and an MLP-based grounded model with multimodal fusion and InfoNCE contrastive learning. Rigorous statistical evaluation pipeline: permutation testing, Representational Similarity Analysis (RSA), Jensen-Shannon divergence, bootstrap confidence intervals, Pearson/Spearman correlation. Result: grounded model achieves 73.5% vs 57.2% text-only accuracy on novel concept association (p=0.0028).
